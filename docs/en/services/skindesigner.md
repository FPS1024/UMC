# Skin designer

The UMC Skin Designer is a planned optional web application for creating and hosting Minecraft: Java
Edition skins.

## Status

Not implemented yet. This page describes the intended scope.

## Intended behavior

- Sign in with an UMC Auth account or an operator-approved authentication service.
- Draw and edit the classic 64×64 skin layout with a small browser editor.
- Preview front, back, and side views before saving.
- Upload and replace a skin for the signed-in account.
- Validate PNG dimensions and alpha requirements before accepting a file.
- Serve texture metadata that a Minecraft server or launcher can consume.
- Let operators disable uploads or enable a moderation queue.

## Security model

- Uploads are limited to PNG and a maximum size.
- File names and paths are generated by the service, never taken from the client.
- Only the authenticated account may replace its own skin.
- The service does not grant Minecraft account ownership; it is a texture host.
- Operators should treat uploaded images as user content and apply their own moderation policy.

## Relationship to UMC Auth

The skin designer can use [UMC Auth](./auth) for accounts and sessions, but it should remain a
separate Docker image. A community can run the auth service without the designer, and the designer
should not be required for normal Minecraft login.
