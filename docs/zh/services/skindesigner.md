# 皮肤设计器

UMC 皮肤设计器是计划中的可选 Web 应用，用于创建和托管 Minecraft: Java Edition 皮肤。

## 状态

尚未实现。本页描述预期范围。

## 预期行为

- 使用 UMC Auth 账号或运营者批准的其他认证服务登录。
- 在浏览器中编辑经典 64×64 皮肤布局。
- 保存前预览正面、背面和侧面。
- 为当前登录账号上传或替换皮肤。
- 接收前校验 PNG 尺寸和透明度要求。
- 提供 Minecraft 服务端或启动器可读取的纹理元数据。
- 允许运营者关闭上传或启用审核队列。

## 安全模型

- 上传只接受 PNG，并限制最大尺寸。
- 文件名和路径由服务生成，绝不采用客户端提供的路径。
- 只有已登录账号可以替换自己的皮肤。
- 该服务不授予 Minecraft 账号所有权，它只是纹理托管方。
- 运营者应把上传图片视为用户内容，并执行自己的审核政策。

## 与 UMC Auth 的关系

皮肤设计器可以使用 [UMC Auth](./auth) 处理账号和会话，但应保持为独立 Docker 镜像。社区可以只运行认证服务而不运行设计器，设计器也不应成为正常 Minecraft 登录的必需组件。
