# 镜像站

UMC 镜像站是计划中的可选服务，用于缓存或代理启动器需要的文件：

- Mojang 版本清单和版本元数据
- 客户端 JAR
- 库文件
- 资源文件
- Java 运行时下载
- 加载器元数据和安装器产物

## 状态

尚未实现。本页描述预期范围，方便启动器集成方提前规划。

当前 `umc` 引擎直接从 Mojang 和相关加载器服务下载文件，并使用上游公布的 SHA-1 校验。

## 预期行为

- 作为独立 Docker 镜像运行，放在 HTTPS 反向代理后面。
- 接受上游基础 URL 和本地缓存目录。
- 服务前先按上游哈希校验每个缓存对象。
- 保持上游目录结构，客户端可以在直连和镜像地址之间切换。
- 暴露简单的健康检查和统计接口。
- 镜像中不捆绑 Minecraft 游戏文件。
- 支持运营者配置的保留时间和缓存大小限制。

## 第一版不做的事

- 用户账号
- 模组或整合包托管
- 启动器认证
- 改写或修改游戏文件

镜像站应当是透明缓存，而不是用于分发运营者无权分享内容的平台。

## 与 UMC Auth 的关系

镜像站独立于 [UMC Auth](./auth)，不需要账号，也不验证玩家。社区可以只运行其中一个、两个都运行，或者都不运行。
