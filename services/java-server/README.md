# UMC Java Edition server

Planned optional Docker service for running a Minecraft: Java Edition server.

The service will manage server versions, memory, world data, logs, and optional authlib-injector
integration with UMC Auth. It is not implemented yet.

Documentation: [English](https://umc-community.github.io/Docs/en/services/java-server) · [简体中文](https://umc-community.github.io/Docs/zh/services/java-server)
